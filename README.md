# 🚢 Titanic Survival Analysis

## 📖 Project Overview

This project performs an Exploratory Data Analysis (EDA) on the Titanic dataset to identify the key factors that influenced passenger survival.

The analysis includes:

- Data Cleaning
- Feature Engineering
- Statistical Analysis
- Data Visualization
- Interactive Dashboard Creation

## 🔍 Key Insights

- Female passengers had significantly higher survival rates than male passengers.
- First-class passengers were more likely to survive than passengers in lower classes.
- Higher ticket fares were positively associated with survival probability.
- Children generally showed better survival outcomes.
- Family size had a noticeable impact on survival likelihood.
